# Software People Levels (>= Senior SWE)

- **Senior Software Engineer**
- **Staff Engineer**
- **Senior Staff Engineer**
- **Principal Engineer**
- **Distinguished Engineer**
- **Fellow**

## Management ladder (parallel track; not 1:1)
- **Engineering Manager**
- **Senior Engineering Manager**
- **Director of Engineering**
- **Senior Director of Engineering**
- **VP Engineering**
- **SVP/EVP Engineering**
- **CTO**
