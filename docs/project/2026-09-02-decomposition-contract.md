# softwareco-agents decomposition contract

This repository is a transitional incubation and discovery surface. It does not become the long-term semantic owner for society or company agents. Role/persona/history migrate to one standalone repository per agent under the appointing jurisdiction; company baseline moves to the SoftwareCo agents lane; shared law, L0 shape, provider content, release/permit, and runtime/effects remain with their existing owners.

Decomposition preserves history and crosslinks, publishes redirects before retirement, and never treats proxy transfer as implementation completion. Retirement is Stage B and occurs only after owners accept replacements, compatibility checks pass, and rollback/archival are recorded. Gate A does not delete, archive, or move this repository.
